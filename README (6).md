## Overview
This repository contains my submission for the Day 9 assignment. The goal of this project is to demonstrate data manipulation and cleaning skills using Python's `pandas` library. I took three separate raw e-commerce datasets (Orders, Customers, and Products) and combined them into a single, clean, processed dataset ready for analysis.

## Files in this Repository
* `orders.csv`: Raw order transaction data.
* `customers.csv`: Raw customer demographics and membership data.
* `products.csv`: Raw product catalog data.
* `Day9_Assignment.ipynb`: The Jupyter Notebook containing the full data processing pipeline.
* `Processed_Ecommerce_Dataset.csv`: The final, combined, and cleaned dataset generated by the notebook.

## Key Pandas Concepts Demonstrated
* **Loading Data:** Reading multiple CSV files into DataFrames.
* **Concatenation (`pd.concat`):** Vertically stacking batches of order data to simulate assembling fragmented datasets.
* **Merging (`pd.merge`):** Performing SQL-style inner joins to relate Orders to Customers (via `Customer_ID`) and Products (via `Product_ID`).
* **Data Transformation (`apply`):** Using lambda functions to categorize order sizes into 'Bulk' or 'Standard'.
* **DateTime Operations:** Converting string dates to datetime objects and extracting human-readable features like month names and days of the week.
